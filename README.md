# westpac-kiwisaver-scheme-calculator

### Prerequisites

Ensure you have the following software installed on your machine:

- Node
- Git
- Visual Studio code
- Playwright Test for VSCode plugin 


### Installation

1. Clone the repository:

```bash
git clone https://github.com/rahulanwekar23/westpac-kiwisaver-scheme-calculator.git
```

2. Navigate to the project directory:

```bash
cd westpac-kiwisaver-scheme-calculator
```

3. Install the dependencies:

```bash
npm install
```

4. Install the Playwright browsers

```bash
npx playwright install
```



### Project Structure
- tests -> contains the playwright test
- pageObjects -> paga object class for each pages which contains the locstors and action
- playwright.config.ts -> contains the playwright test configuration
